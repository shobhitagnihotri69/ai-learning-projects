## 🎯 The Top Immediate PR Opportunities (Zero Competing PRs)

### 1. Boundary (`BoundaryML/baml`) — **Issue #4901**
- **Issue**: `[bug] Node bridge 0.19.0: a host callable returning an integral number for a float panics with HostContractViolation`
- **Opened**: ~20 hours ago | **0 competing PRs**
- **File**: `baml_language/crates/bex_external_types/src/host_return.rs` & `baml_language/sdks/typescript/bridge_typescript/typescript_src/proto.ts`
- **Root Cause**: In JS, numbers like `1` or `612` are integers (`Number.isInteger(612) === true`). The bridge encodes them as `intValue`. In Rust, `validate_host_return` rejects `Int` for `RuntimeTy::Float` without allowing boundary int→float widening, triggering a fatal panic.
- **Fix**: Widen `Int` into `Float` at the return validation boundary (matching engine's `coerce_numeric_to_declared_type`).

### 2. Mem0 (`mem0ai/mem0`) — **Issue #7349**
- **Issue**: `bug(oss): ConfigManager injects OpenAI's baseURL and model into every other LLM provider`
- **Opened**: ~2 days ago | **0 competing PRs**
- **File**: `mem0-ts/src/oss/src/config/manager.ts`
- **Root Cause**: `DEFAULT_MEMORY_CONFIG.llm.config` injects OpenAI's default `baseURL` into non-vLLM providers, overriding environment variables like `DEEPSEEK_API_BASE` and `XAI_API_BASE` and routing non-OpenAI models to OpenAI servers.
- **Fix**: Ensure default `baseURL` is provider-scoped so other LLM providers can fall back to their respective endpoints and environment variables.

### 3. Onyx (`onyx-dot-app/onyx`) — **Issue #14858**
- **Issue**: `Bug: EXT_PERM_USER from connector prevents creating the corresponding real user`
- **Opened**: ~5 hours ago | **0 competing PRs**
- **File**: `backend/onyx/auth/users.py` / connector identity management
- **Root Cause**: External permission sync creates `EXT_PERM_USER` placeholders. Later admin user creation fails with "user already exists" while omitting the user from the admin list.
- **Fix**: Automatically convert or promote `EXT_PERM_USER` placeholders when a real web-login user is created.
