## What This Is

A structured 10-day bootcamp covering the full landscape of AI agent frameworks — from basic ReAct agents to production-grade multi-agent systems. Each directory contains working code, notebooks, and industrial project implementations.

---

## Frameworks Covered

| Directory | Framework | What You Build |
|:---|:---|:---|
| `CrewAI/` | [CrewAI](https://github.com/joaomdmoura/crewAI) | Multi-agent crews with role-based task delegation |
| `LangGraph/` | [LangGraph](https://github.com/langchain-ai/langgraph) | Stateful agent workflows as computational graphs |
| `LlamaIndex/` | [LlamaIndex](https://github.com/run-llama/llama_index) | RAG-powered agents with structured data retrieval |
| `Smolagents/` | [Smolagents](https://github.com/huggingface/smolagents) | Hugging Face's lightweight agent framework |
| `The-Agents-Book/` | Multiple | Foundational concepts — ReAct, tool use, memory, planning |
| `Industrial Projects/` | Mixed | Real-world applications combining multiple frameworks |

---

## Quick Start

```bash
# Navigate to any framework directory
cd CrewAI/

# Install dependencies (each has its own requirements)
pip install -r requirements.txt

# Run the example
python main.py
```

## Learning Path

| Day | Topic | Framework |
|:---|:---|:---|
| 1–2 | Agent fundamentals, ReAct pattern, tool calling | The-Agents-Book |
| 3–4 | RAG agents and structured retrieval | LlamaIndex |
| 5–6 | Multi-agent systems with role delegation | CrewAI |
| 7–8 | Stateful workflows and graph-based agents | LangGraph |
| 9 | Lightweight agents | Smolagents |
| 10 | Industrial capstone projects | Industrial Projects |
