# Agents Bootcamp — Beginner Friendly

A beginner-friendly guide to building real AI agents across 5 major frameworks.

Covers building real AI agents with:
- **CrewAI** — Multi-agent collaboration
- **LangGraph** — Agent workflows as graphs
- **LlamaIndex** — Agentic RAG
- **Smolagents** — Lightweight browser agents

## Structure

| Folder | Topics |
|--------|--------|
| `CrewAI/` | Blog writer, customer outreach, financial analysis, job application booster |
| `LangGraph/` | Email sorting, vision agent, travel agent, resume checker |
| `LlamaIndex/` | Agentic RAG |
| `Smolagents/` | Browser agent, vision agent, multi-agent |
| `Industrial Projects/` | End-to-end real-world agent projects |

## Getting Started

```bash
pip install crewai langgraph llama-index smolagents python-dotenv
```

Create a `.env` file with your API keys:
```
OPENAI_API_KEY=your_key_here
```
