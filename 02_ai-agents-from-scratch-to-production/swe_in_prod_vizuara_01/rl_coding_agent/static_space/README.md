# 🚀 OpenCodingEnv

An open-source, verifiable Reinforcement Learning (RL) execution sandbox & GRPO training harness for coding agents.

Compatible with **Hugging Face TRL `GRPOTrainer`**, **OpenEnv**, and **SWE-bench**.
